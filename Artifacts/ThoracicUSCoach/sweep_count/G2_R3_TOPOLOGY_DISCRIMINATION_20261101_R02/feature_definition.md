# G2-R3 Feature Definition

Selected family: acoustic-shadow onset/termination continuity. A bright-interface valley remains eligible only when at least 45 image pixels remain distal to the 75th-percentile tracked interface depth. This is the minimum field needed to inspect a post-interface shadow rather than accepting a deep image-boundary contour. The same rule is applied to every candidate. Insufficient field yields AMBIGUOUS, not a claim that the physical structure is absent. The threshold is development-tuned on all three G2-R2 sweeps and must be frozen before confirmation.
